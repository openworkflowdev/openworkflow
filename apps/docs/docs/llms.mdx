## Set up OpenWorkflow with an assistant

Open your project in your AI coding assistant and paste this prompt:

```text
Read and follow https://openworkflow.dev/skills/setup.md to set up OpenWorkflow.
```

The [agent setup guide](/skills/setup) walks your assistant through
inspecting the project, installing OpenWorkflow, and running an example
workflow to verify the setup.

## Plain-text docs for LLMs

Append `.md` to any docs URL to retrieve the page as plain-text Markdown. For
example, this page is available at
[https://openworkflow.dev/docs/llms.md](https://openworkflow.dev/docs/llms.md).

OpenWorkflow also provides `/llms.txt` at the root of the docs site. It follows
the emerging standard and maps the documentation so agents can find each
page's plain-text version.
